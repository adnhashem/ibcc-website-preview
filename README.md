# ib-cc.de – six website directions

Design preview for C&C Ingenieure GmbH: six design directions (W1–W6) for the public website www.ib-cc.de, each with a 15-slide presentation of its live screens.

Open: https://adnhashem.github.io/ibcc-website-preview/ — the page starts with a language choice (العربية · English · Deutsch).

Draft for review, not a finished website.

## Round 4 (2026-10-14)

Six proposals in dark green with an orange accent, motion and a German/English switch, each with all seven pages: P1 «Schichten», P2 «Trasse», P3 «Phasen» (drawings, on the client's own mockup) and P4 «Panorama», P5 «Doppelseite», P6 «Mosaik» (photo-led, each a different presentation; sample photos are licensed Wikimedia Commons images, credited on the pages).

Open: https://adnhashem.github.io/ibcc-website-preview/r4/
